## 三、验证方法（无打印机）

### 1. 导出 PDF

- 应用内：打印模板页选目标 →「导出 PDF」，保存到本地。
- 离线复现（开发用）：用离屏 `WKWebView` 加载打印视图 HTML 与 `@page` CSS，执行
  `printOperationWithPrintInfo:` + `NSPrintInfo`（`NSPrintSaveJob`），与单机版
  `shell/mac/webview.mm` 的导出链路一致。本次即用该方法核对 MediaBox。

### 2. 查看纸张尺寸

```bash
mdls -name kMDItemPageWidth -name kMDItemPageHeight -name kMDItemNumberOfPages export.pdf
```

或直接读 PDF 的 MediaBox：

```bash
python3 - <<'PY'
import re
data = open('export.pdf','rb').read()
print(set(re.findall(rb'/MediaBox\s*\[([^\]]+)\]', data)))
PY
```

### 3. 期望值（pt，1 mm = 72/25.4 pt）

| 纸型 | 纵向 MediaBox | 横向 MediaBox |
| --- | --- | --- |
| A4 | 595 × 842 | 842 × 595 |
| 针式 241×140 | 683 × 397 | 397 × 683 |
| 针式 241×93 | 683 × 264 | 264 × 683 |

本次实测：A4 为 `0 0 595 842`；两个针式纸型同样输出 `0 0 595 842`，与期望值不符。

### 4. 列宽与边距的关系

可打印宽度 = 纸张宽度 − 2 × `margin_mm`。默认 12 mm 边距下：

- A4：186 mm
- 241 mm 针式：217 mm

用 `/api/print/targets` 返回的 `columns[].width_mm` 求和即可判断是否超出；采购明细 252 mm 已超出两种纸型。

## 四、本次确认的问题（待决定后再改，未改默认值）

1. **PDF 导出不采用模板纸型**：`savePdfWithFilename` 与 `printDocument` 均使用
   `NSPrintInfo sharedPrintInfo`，未按模板 `page_size / paper_width_mm / paper_height_mm`
   设置 `paperSize`，`@page size` 在该链路下不改变 MediaBox。针式纸型导出 PDF 会得到系统默认 A4。
2. **宽表超出可打印宽度**：采购明细 252 mm、资金流水 214 mm、收发明细 200 mm，
   在 A4（186 mm）与 241 mm 针式（217 mm）下都会横向溢出，存在裁切风险。
