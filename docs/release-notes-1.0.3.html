小兔进销存 1.0.3

发行日期：2026-11-19 · 适用平台：Windows 10/11、macOS 14+（Apple Silicon）

Windows 自动更新

  • 新增更新清单升级为 macOS / Windows 共用的统一清单，下载包先做 Ed25519 签名校验和 SHA256 校验，校验通过才允许安装。
  • 修复「下载并校验」完成后，检查结果会变回「尚未检查」的问题。
  • 修复点「安装更新」后没有任何反应的问题：安装程序现在会先关闭正在运行的程序，再覆盖安装，装完自动启动新版本。
  • 修复下载或安装失败时没有任何提示的问题：失败原因会直接显示在更新卡片上。
  • 修复已下载并校验过的安装包会被保留，安装时不再重复下载。
  • 检查、下载、安装的关键结果会写入 logs/app.log，便于排查。

稳定性与数据安全

  • 修复报表查询参数非法时未报错、limit 被解析成不限行数的问题。
  • 修复导出的 CSV 中，以 = + - @ 开头的单元格会被表格软件当公式执行的风险，现已自动转义。
  • 修复大导出或大批量写入时，其余请求被长时间阻塞的问题（读连接池与写锁等待都加了超时）。
  • 修复流式导出异常会导致整个服务进程退出的问题。
  • 修复导入超大数值、xlsx 文件头越界等边界情况。

界面与安装

  • 修复Windows 应用图标发糊的问题（改为多尺寸图标）。
  • 修复macOS 安装镜像卷名为中文时，自动化环境安装被系统拦截的问题。

已知限制

  • Windows 安装包暂未做代码签名，首次运行时可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」即可。
  • Windows 端暂不支持「回退到上一版本」和「打开备份目录」，这两项目前仅 macOS 提供。
更新前建议先在「数据备份」里做一次手动备份。升级后如遇异常，可从 backups/ 目录恢复升级前的自动备份。
