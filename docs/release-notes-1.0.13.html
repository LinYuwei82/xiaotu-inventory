小兔进销存 1.0.13

本次更新（macOS）

  • 安全与缺陷修复批次：
    • 零金额库存流水：v40 迁移放宽约束，赠品 0 价入库、零成本出库、盘盈 0 价等合法流水不再被拦；数量与金额同为 0 的无效流水仍拒绝。老版本数据库升级可平滑穿过旧约束。
    • 期初导入拒绝 0 成本单价，零成本商品请走其他入库（赠品）。
    • 会话、CSRF、免输凭据、换票、关机令牌与口令盐全部改用密码学安全随机源；前端请求幂等键同步加固。
    • 订单下推接入信用额度检查，与手工审核同口径；超额警告后需二次确认方可继续，确认放行写入审计。
    • 客户合并后已占用额度沿合并链汇总统计，杜绝跨档案漏算导致的额度稀释；合并链查询加防成环上限。
    • 订单下推新增幂等键：双击或网络重试不会生成两张出库单，已下推数量不会重复累计。
    • 接口整数参数非法一律返回 400；服务器内部错误不再回显技术细节。
  • 手动「检查更新」冷却从 10 分钟缩短为 1 分钟。
  • macOS 出包改进：.app 本体也注入公证票据（staple），拖入「应用程序」后断网首启不再弹「无法验证」。

构建与分发

  • 本次为 macOS 单平台更新，构建号 9；Windows 仍为 1.0.12（构建号 8）。

升级说明

  • 1.0.11/1.0.12 用户可直接在应用内「检查更新 → 安装更新」，或下载 DMG 覆盖安装；数据库自动迁移到 schema v40，升级前请先备份。
