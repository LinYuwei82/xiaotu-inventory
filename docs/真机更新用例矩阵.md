# 真机更新用例矩阵（mote 模式改造后）

适用版本：≥ 1.0.24（Windows 提交 6402882/18db7fc，macOS 提交 df9eca8/bd2c47d）
测试环境：Windows 12600K 真机 + Apple Silicon Mac；旧基线客户端 = 线上 1.0.23

## 测试基建准备

1. **测试清单**：用测试私钥签 `version=1.0.99` 的 v2 清单
   `python3 tools/release/manifest_v2.py generate --product xiaotu --channel stable --version 1.0.99 --build <N> --artifact setup=<ISCC 产物> --artifact portable=<zip 产物> --artifact dmg=<本地 dmg>`
2. **本地清单服务**：`python -m http.server 8000`（Windows 在测试机跑，macOS 本机跑）
3. **壳指向测试清单**：
   - Windows：`set XIAOTU_UPDATE_URL=http://127.0.0.1:8000/manifest.json` 后启动 xiaotu-shell.exe
   - macOS：`XIAOTU_UPDATE_URL=http://127.0.0.1:8000/manifest.json open xiaotu-inventory.app`（Sparkle 段用例需把 appcast 一并指到测试地址，或走 staging OSS 目录）
4. 每轮测试前备份 `%LOCALAPPDATA%\com.simem.xiaotu\`（win）/ `~/Library/Application Support/com.simem.xiaotu/`（mac），便于重复执行。
