下载

平台 文件 说明

Windows xiaotu-1.0.6-win64-setup.exe 安装版

校验

随附 SHA256SUMS.txt，下载后可自行校验：

# macOS / Linux
shasum -a 256 -c SHA256SUMS.txt

# Windows
certutil -hashfile xiaotu-1.0.6-win64-setup.exe SHA256

系统要求

  • macOS 13.0 及以上（Apple Silicon）
  • Windows 10 及以上（64 位）
