小兔进销存 1.0.26

本次更新（Windows 自动更新修复）

  • 修复自动更新「卡死」：检查更新、安装包校验全部移到后台线程，点击「检查更新」不再让窗口无响应。
  • 修复自动更新「闪退」：更新回调统一封送到 UI 线程，不再从下载/安装线程直接操作 WebView2；安装失败时也不会再无提示地关窗。
  • 安装过程可诊断：安装器增加 /LOG 与拉起标记；下次启动会显示上次安装成功或失败，并附带安装日志尾部，便于定位原因。
  • 绿色版安装不再闪退：MANUAL 分支改为在界面提示手动解压覆盖，程序保持打开并可重试。
  • 修复中文状态文案乱码；下载安装包不再整包驻留内存；下载进度落盘改为每秒最多一次。
  • 修复 Windows 壳在 MSVC 下因 WinHttpSetOption 传 const 指针导致的编译失败。

构建与分发

  • Windows 构建号 22；macOS 保持不变（1.0.25）。

升级说明

  • 1.0.25 用户可直接在应用内「检查更新」→「安装更新」一键完成；升级前请先备份。
  • 上次自动更新失败的用户，可在「设置 → 软件更新」重试；失败详情会显示安装日志末尾。
  • Windows 安装包尚未启用 Authenticode 签名，首次运行仍可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」即可。

系统要求

  • Windows 10/11 64 位；桌面窗口需要 WebView2 Runtime（安装包可自动安装）
