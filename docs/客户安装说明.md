# 小兔进销存 · Windows 安装说明

你好，感谢试用小兔进销存！这份文档告诉你怎么装、怎么用，以及第一次打开会看到什么。

---

## 一、安装

双击 `xiaotu-1.0.11-win64-setup.exe` 开始安装。

### 会弹一个蓝色警告？正常的。

**Windows SmartScreen** 会拦住没有数字签名的新软件——这不是安装包有病毒，只是我们还在早期、没来得及买签名证书。处理一下就行：

1. 看到 **「Windows 已保护你的电脑」** 蓝色弹窗，点下方的 **「更多信息」**
2. 展开后点 **「仍要运行」**
3. UAC 再确认一次，点 **「是」** 就进入安装向导了

同一个安装包**只需要放行一次**。装完以后桌面/开始菜单的快捷方式直接双击就能开，不会再弹这个提示。换新版本的安装包时，会再拦一次（每个新安装包哈希不同），同样点「更多信息 → 仍要运行」即可。

### 安装过程

- 默认装到你自己账户的 `%LOCALAPPDATA%\Programs\小兔进销存`，不需要管理员权限
- 桌面和开始菜单各有一个「小兔进销存」快捷方式
- 数据保存在 `%LOCALAPPDATA%\com.simem.xiaotu\app.db`，**卸载不会删除数据**，放心装

## 二、首次启动

双击桌面图标打开。第一次用需要设置管理员口令（至少 8 位，自己记好）。

### 窗口一片空白？装一下 WebView2

> 用安装包装时，「附加任务」里的「下载并安装 WebView2 运行环境」默认勾选，保持勾选并联网即可自动装好；IT 静默安装（`/VERYSILENT`）也会自动装。取消过或用的是绿色版，再按下面手动安装。

桌面窗口依赖系统的 **WebView2 Runtime**（Windows 11 自带，部分 Windows 10 没有）。如果双击后是空白窗口或提示缺少组件：

👉 打开 <https://go.microsoft.com/fwlink/p/?LinkId=2124703> 点 **Download Now**，下载一个约 2MB 的安装包，装完再双击小兔进销存即可。

## 三、安装包安全吗？

如果你想确认安装包没被篡改，可以用 SHA256 哈希核对。安装完成后，按 **Shift + 右键** 安装包所在文件夹的空白处 → **在此处打开 PowerShell**，粘贴这条命令：

```powershell
Get-FileHash -Algorithm SHA256 ".\xiaotu-1.0.11-win64-setup.exe"
```

输出的 `Hash` 字段应该跟发版消息里给你的 SHA256 完全一致。

## 四、常见问题

| 问题 | 怎么办 |
| --- | --- |
| 杀毒软件（Defender/360）报毒 | 未签名 exe 偶尔会被杀软误报。先核对 SHA256，一致的话就是误报，把 `xiaotu-shell.exe` 和 `xiaotu-server.exe` 加到信任列表即可。 |
| 数据在哪个文件夹？ | `%LOCALAPPDATA%\com.simem.xiaotu\`，里面的 `app.db` 是主数据库，`backups\` 是自动备份。 |
| 能不能在另一台电脑上也装一份？ | 可以，每台电脑第一次安装各自放行一次就行。 |
| 以后想换电脑？ | 把数据目录里的 `app.db` 和 `backups\` 整文件夹拷过去，新机器上装完直接替换即可。 |
| 想在局域网里多人用？ | 这是网络版能力。启动服务端加上 `--server` 参数，其他人浏览器打开你的 IP + 端口就能访问，具体命令见 `README.md`。 |
