## 小兔进销存 1.0.12

### 本次更新

- **修复 Windows 应用内更新后程序不再启动（表现为「点安装更新就闪退」）**：此前的安装包在静默安装时跳过了「启动应用」这一步，壳又是由安装脚本关闭的、不受 Windows 重启管理器管辖，因此安装完成后没有任何进程被拉起，窗口消失后就不再回来。1.0.12 起，静默覆盖更新完成后会自动启动新版本；首次无人值守静默安装（不覆盖已有安装）不会额外弹出窗口。
- **不受影响的场景**：手动双击安装包、开始菜单「检查更新 → 安装更新」之外的升级路径行为不变；数据目录与数据库迁移逻辑未改动。

### 临时规避（尚未升级到 1.0.12 时）

在旧版本里点过「安装更新」后，如果程序窗口消失且没有自动回来，从开始菜单或桌面快捷方式重新打开即可 —— 此时新版本通常已经装好，重新打开后可在「关于」里核对版本号。

### 构建与分发

- 本次为 Windows 单平台修复，构建号 `8`；macOS 仍为 1.0.11（构建号 `7`）。

### 校验

随附 `SHA256SUMS.txt`，下载后可自行校验：

```bash
# macOS / Linux
shasum -a 256 -c SHA256SUMS.txt

# Windows
certutil -hashfile xiaotu-1.0.12-win64-setup.exe SHA256
```

### 升级说明

- 可直接下载本次安装包覆盖安装，或在应用内「检查更新」升级。
- Windows 安装包尚未启用 Authenticode 签名，首次运行仍可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」即可。

### 系统要求

- macOS 13 及以上（Apple Silicon）
- Windows 10/11 64 位；桌面窗口需要 WebView2 Runtime（安装包可自动安装）
