## 小兔进销存 1.0.27

### 本次更新（Windows 更新提示修复）

- **修复软件更新区域空白**：进入「系统 → 关于与诊断」时，壳会主动推送一次状态快照，检查结果、上次检查时间、待安装版本无需先点「检查更新」即可显示。
- **修复重启后不提示上次安装结果**：安装结果与状态一起随启动快照推送，「更新成功 / 上次更新没有完成」会正常出现；提示后自动清理标记，不会重复弹出。
- **失败提示带具体原因**：安装程序提前退出时提示形如「无法启动安装流程：安装程序启动失败（SETUP_EXITED_EARLY=1）」，持续提示中还会附带安装日志尾部与原因，便于直接定位。
- 状态请求在旧壳上自动回退到原有接口，兼容旧版本。

### 构建与分发

- Windows 构建号 `23`；macOS 保持不变（1.0.25）。

### 下载

| 平台 | 文件 | 说明 |

| Windows | `xiaotu-1.0.27-win64-setup.exe` | Inno Setup 安装包 |
| Windows | `xiaotu-1.0.27-win64-portable.zip` | 绿色版 |

### 升级说明

- 1.0.26 用户可直接在应用内「检查更新」→「安装更新」一键完成；升级前请先备份。
- **1.0.25 及更早版本**的自动更新链路存在缺陷（失败时会无提示关窗），建议手动下载 `xiaotu-1.0.27-win64-setup.exe` 覆盖安装一次，之后即可正常使用应用内更新。
- Windows 安装包尚未启用 Authenticode 签名，首次运行仍可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」即可。

### 系统要求

- Windows 10/11 64 位；桌面窗口需要 WebView2 Runtime（安装包可自动安装）
