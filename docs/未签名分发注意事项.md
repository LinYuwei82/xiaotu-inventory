## 第一部分：给客户（可随包转发）

### 为什么会弹出「Windows 已保护你的电脑」？

Windows 有一套叫 **SmartScreen** 的安全机制，会拦截「没有数字签名」或「下载量极少」的安装包。这不是安装包有病毒，只是我们还没有购买代码签名证书。

macOS 版本已通过 Apple Developer ID 签名并公证，正常双击即可打开，不会被 Gatekeeper 拦截。

### 首次安装指引（Windows）

1. 双击 `xiaotu-inventory-0.9.0-win64-setup.exe`。
2. 出现 **「Windows 已保护你的电脑」** 蓝色弹窗时，点 **「更多信息」**。
3. 弹窗底部会展开一条 **「仍要运行」** 按钮，点它。
4. UAC 可能再问一次「是否允许此应用对你的设备进行更改」，点 **「是」**。
5. 之后就是正常的安装向导，不需要管理员权限，默认装到你自己账户的 `%LOCALAPPDATA%\Programs\小兔进销存`。

### 每次都要点吗？

**同一个安装包只需放行一次**。安装完成后，桌面/开始菜单的快捷方式直接双击就能打开，不会再弹 SmartScreen。

**换了新版本怎么办？** 下载新的安装包后，同样会被拦一次，点一次「更多信息 → 仍要运行」即可，逻辑和首次一样。

### 安装包真的安全吗？怎么验？

下载安装包后，可以用 SHA256 哈希值核对：如果跟下面给出的哈希一致，说明包没有被篡改。

#### PowerShell（推荐）

```powershell
Get-FileHash -Algorithm SHA256 "<安装包完整路径>"
```

输出的 `Hash` 字段应该跟发版消息里的 SHA256 完全一致。

#### 没有 PowerShell？

打开安装包所在文件夹，按住 **Shift + 右键** 空白处 → 「在此处打开 PowerShell」，粘贴上面的命令回车即可。

#### macOS 用户（不需要验签，但想确认 SHA256 也行）

```bash
shasum -a 256 "<dmg 路径>"
```

### 安装后常见问题

| 问题 | 解决方法 |
| --- | --- |
| 双击桌面图标没反应 / 白屏 | 你的机器没有 WebView2 Runtime。打开 <https://go.microsoft.com/fwlink/p/?LinkId=2124703> 点「Download Now」装一下，几十 MB。装完重新双击即可。 |
| 启动后要求输入管理员口令 | 这是你**首次安装**，系统里还没有账号。按界面提示设置一个至少 8 位的口令即可。 |
| 数据存在哪？ | Windows：`%LOCALAPPDATA%\com.simem.xiaotu\app.db`。备份文件也在同一目录的 `backups\` 子文件夹。卸载**不会删除**数据目录。 |
| 能不能装给公司里其他电脑用？ | 可以。每台电脑首次运行都需要自己放行一次（SmartScreen 是按设备、按文件算的）。 |
| 杀毒软件报毒？ | 未签名的 exe 有时会被 Defender / 360 报「未知行为」或「Trojan.Generic」误报。先确认 SHA256，一致的话就是误报，把安装包和 `xiaotu-shell.exe` / `xiaotu-server.exe` 加到杀毒软件的信任列表里。 |

### 还是不敢装？

如果你不放心，可以：

1. 要到安装包后先用杀毒软件扫描一遍；
2. 核对 SHA256；
3. 在虚拟机里先试装一次；
4. 遇到任何疑问直接联系发版人。

### 常见边界

- **Defender / 360 误报**：未签名 exe 的启发式扫描偶尔会报「未知行为」或「Generic」病毒。这是杀软对未知文件的保守策略，不是真病毒。核对 SHA256 后可以放心加入信任列表。
- **SmartScreen 信誉累积**：即使以后签了 OV 证书，SmartScreen 的信誉也需要时间积累（通常几百到几千次下载后才不会再拦）。EV 证书可以快速获得信誉，但成本更高。
- **CI 不能直接用 Certum SimplySign**：SimplySign 依赖桌面登录会话，GitHub 托管 runner 用不了。需要在本机或自托管 runner 上打包签名，或改用带 API 的云签名服务。
- **不要把 PFX 放进仓库**：即使买了证书，私钥也只能走环境变量或 secret 注入，绝对不能提交到 git。当前 CI 的 `WINDOWS_CERT_PFX_BASE64` / `WINDOWS_CERT_PFX_PASSWORD` 两个 secret 已预留。
